RetailIQ — E-commerce Sales & Inventory Analytics
Project Overview

RetailIQ is an advanced MySQL project designed to analyze e-commerce sales, customer purchasing behavior, payments, and inventory.

Key Features
Relational database design with primary and foreign keys
Monthly revenue and growth analysis
Customer lifetime value analysis
Top product rankings using window functions
Inventory reorder alerts
Payment reconciliation
Common Table Expressions (CTEs)
Views and stored procedures
Inventory validation and deduction triggers
Indexes for query optimization
How to Run
Install MySQL 8.0 or later.
Open MySQL Workbench and connect to your MySQL server.
Run the SQL scripts in the order documented in the project.
Execute the analytics queries and inspect their results.
Learning Outcomes

Practiced advanced SQL, relational database design, data integrity, reporting, and business analytics.

Project Type

Portfolio project for SQL / MySQL developer and data analyst roles.
